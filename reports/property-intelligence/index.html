The project

Built like a research project.

Property decisions often rely on a number nobody can inspect: no inputs, no error, no date.

We built this engine so the method can be checked. Public listing data and council valuations go in. The method is simple: compare similar properties, test on data kept out of training, measure the error, and state the limits. Every range names its source.

We also show where it is weak. Text analysis helped when the council valuation was missing, but no topic survived correction, so it is not used in valuation.

Method

From a listing page to a value range.

Each range uses the best available signal, labels it, and states its limits. Listings also flag school-zone coverage, recent price or copy changes and repeated sales as context, not automatic price changes.

  1. 01 Recover the price signal

    Asking price, guide, deadline or auction date, read from the listing page and dated.

  2. 02 Value the tenure

    Tenure is checked before a value is produced, because leasehold and cross-lease homes are not directly comparable with freehold.

  3. 03 Compare nearby sales

    Sold prices weighted by distance and recency, normalised by council capital value where one is available.

  4. 04 Calibrate a fallback

    A calibrated fallback model for listings without an AVM or usable comparables, with an 80% interval and published error.

Read the methodology or download the PDF. Each listing also carries source-backed tenure, approximate build year and previous sale history where a Homes.co.nz match exists.

What this is — and what it is not

  • Full map with listing summaries. Click a map bubble for the listing drawer. The results list and filters are in the embedded map.
  • Decision support, not a valuation. It does not meet professional valuation standards, cannot replace a registered valuer, and is not financial, legal or tax advice.
  • A snapshot, not a live feed. Figures refresh daily. Verify the title, any ground rent and consented works before making an offer.
