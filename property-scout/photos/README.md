# Mock property imagery

16 deterministic editorial SVG scenes generated by `scripts/generate-photos.mjs`.
They stand in for Trade Me photos in mock mode so the gallery, cards and
screenshots render identically offline. Regenerate with:

```bash
node scripts/generate-photos.mjs
```

When the live API is wired, `photo_url` simply points at Trade Me's CDN and
these files are no longer referenced.
