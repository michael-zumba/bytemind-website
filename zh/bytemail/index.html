回邮件，不用从头写

选中要回的那封邮件，按一个快捷键，ByteMail 就写出一封你会写的回复。 它不知道的事会留成空格由你来填，所以不会替你编。

回邮件

它做三件事

下面每一段都录自应用本身，两三秒。

写出这封回复

选中邮件，按下 ⌥⌘R，回复就一句句写出来——邮件在哪个程序里都行，浏览器里也可以。

  • 连选中内容前后的文字一起读，知道是谁在问、已经谈定了什么
  • 用你自己发过的邮件当范本，写出来就是你的语气
  • 可以复制走，也可以直接替换掉你选中的那段文字

不知道的，留给你

日期、价格、承诺、人名——凡是它无从知道的，都在草稿里留成一个带标签的空格。

  • 每个空格都写明缺的是什么
  • 空格没填完，复制按钮就一直按不动

学你的语气

贴上几封你自己写的邮件，ByteMail 会记住你的称呼、落款、句子长短，还有那些不像你写的习惯。

  • 描述你文风的档案大约只有 1 KB
  • 你认可的回复会替换掉旧样本，不会越堆越多

这些短片录自应用本身。macOS 版把同样的步骤收进一个快捷键，面板就浮在你的邮件上。

整个过程

三步，一次粘贴

除此之外不再问你别的。

步骤 你要做的
1. 定方向 从两到四个真正不同的回复里挑一个——两个都确认、约个电话。
2. 拿主意 回答两三个问题，大多点一下就行。
3. 出草稿 读一遍，填上只有你知道的事，复制走。
不一样在哪

它不只是个聊天窗口

聊天窗口并不知道自己在回一封邮件，ByteMail 知道。

  聊天窗口 ByteMail
知道这是邮件不知道称呼、落款、篇幅、语气都按邮件来
按你的语气写不会从你自己发过的邮件里学
知道你是谁不知道职位、公司、资历来自你的资料
缺的信息直接编留成空格，复制按钮按不动
读整条往来不会读你选中内容前后的文字

这道关卡你自己就能验。应用自带一个不需要 API 密钥、也不联网的检查 --contracttest，一旦填了空格复制按钮没解锁，它就报错。

它不会做的

  • 不会替你发邮件。它把文字交给你，由你粘进平时用的邮箱。
  • 不会猜事实。你没写进去的日期、价格、承诺，它不会自己写。
  • 不确定就说不确定。它查不了的事，会写成一句提示，写明该去核什么。

在哪里用

  • macOS 版住在菜单栏，一个快捷键，面板浮在你的邮件上。
  • Windows 版在自己的窗口里，结果是一样的。
  • 只发该发的。除了发给你自己选的模型服务，其他都不出本机。
你的邮件

邮件不出你的电脑

不用注册 ByteMind 账号，中间也没有我们自己的服务器。

2.3 MB整个 macOS 应用
1 KB用来描述你文风的那份档案
0账号，也没有行为统计
1联网只发给你选的模型服务

东西存在哪

API 密钥放在 macOS 钥匙串，Windows 上放在系统自带的加密存储里。 你的资料和文风存在应用自己的文件夹。不需要注册账号。

它不会读什么

它只读你选中的文字和周围的正文，不读屏幕上别的内容，也不碰你没让它看的邮箱。 邮件里的图片会被去掉，去掉几张它也会告诉你。

更新会自动装好

  • ByteMail 每隔几小时查一次有没有新版本，有就会告诉你。
  • 点一下安装，它就下载、校验、替换应用，然后重新启动。
  • 辅助功能权限会保留，因为新版本和旧版本由同一张证书签名。

安装前先看这里

  • macOS：ByteMail 已用 ByteMind Ltd 的开发者证书签名，但公证还没完成，所以第一次打开会提示 Apple 无法检查。打开系统设置 → 隐私与安全性，在 ByteMail 旁边点仍要打开再确认。只需一次。
  • macOS：ByteMail 需要辅助功能权限，才能读你选中的文字、把回复放回去。设置里的「权限」会显示状态；不想授权，也可以改用剪贴板方式。
  • Windows：如果出现 SmartScreen 提示，点更多信息，再点仍要运行。
  • 两个版本都一样：可以填自己的模型密钥，也可以指向本机模型，完全不用密钥。安装包放在 GitHub Releases。
