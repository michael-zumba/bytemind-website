ByteProof 隐私政策

生效日期：2026 年 8 月 14 日

ByteMind Ltd（“我们”）运营 ByteProof，这是一款面向 macOS 和 Windows 的桌面 AI 校对应用。本政策说明 ByteProof 收集哪些信息、如何使用这些信息，以及你有哪些选择。

1. ByteProof 是做什么的

ByteProof 校对文本和文档。它在你的电脑上运行本地 AI 模型，你也可以选择用自己的 API 密钥连接云端 AI 服务商（比如 DeepSeek、OpenAI、Anthropic、Google、Groq、xAI、Perplexity，或本地的 Ollama 服务器）。

2. 我们收集的信息

  • 许可和付款详情： 购买 ByteProof 许可证时，我们会收集结账时使用的邮箱地址、你的付款状态，以及用于绑定许可证的机器标识（每个许可证最多绑定两台电脑）。付款由 Stripe 处理；我们不会看到或存储你的银行卡信息。
  • 激活记录： 一条记录，说明你的邮箱地址已在某台电脑上激活 ByteProof，这样才能执行两台电脑的上限。
  • 支持沟通： 你通过电子邮件发给我们的任何信息。

3. 你的文档内容和 AI 处理

  • 本地 AI 模式（默认）： 文本完全在你的设备上处理。文档内容不会发送给我们，也不会发送给任何云服务商。
  • 自带密钥模式： 如果你连接自己的 API 密钥，你选中用于校对的内容会发送给你选择的提供商，并按该提供商的条款和隐私政策处理。你的 API 密钥存在你自己的电脑上，不会存到我们的服务器，我们也看不到。
  • Microsoft Word 集成： Word 文档在你的电脑本地打开，ByteProof 才能插入修订和批注。

4. 自动收集的技术信息

ByteProof 会检查我们的网站有没有新版本。这个请求由我们的托管服务商处理，它可能会记录你的 IP 地址等常规技术信息。ByteProof 不使用分析工具、广告追踪器或遥测功能，我们也不会监控你如何使用这个应用。

5. 我们如何存储和保护信息

许可和激活记录存放在我们位于新西兰的服务器上。许可密钥经过加密签名，并与你的电脑绑定，保存在操作系统的安全凭据存储中（macOS 钥匙串或 Windows 凭据管理器）。我们采取合理的技术和组织措施保护这些信息。

6. 信息共享

我们不会出售你的信息。只与以下对象共享：

  • Stripe — 用于处理付款；
  • 我们的托管和邮件服务商 用于运行许可证服务器并发送激活邮件；
  • 你选择的 AI 提供商 ——只在你使用自带密钥模式时，而且只针对你提交的文本；以及
  • 主管机构 ——如果法律要求我们披露。

7. 数据保留

在你的许可证有效期间，我们会保留许可证和激活记录；之后只在法律、会计或防欺诈所需的期限内保留。你可以随时通过下方联系方式要求我们删除你的记录。

8. 你的权利

你可以向我们索取我们所持有的你的信息副本，也可以要求更正或删除。按照《2020 年新西兰隐私法》的要求，我们会在合理时间内回复。

9. 本政策的变更

我们可能会不时更新本政策。本页顶部的生效日期显示最近一次更新的时间。重要变更会在这里说明，在可行的情况下也会在应用中说明。

10. 联系方式

如果你对隐私有疑问或要求，请联系我们： bytemind.nz@gmail.com，或写信至 ByteMind Ltd, New Zealand。
