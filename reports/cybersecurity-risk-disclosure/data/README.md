# Data and Methodology

Report: Cybersecurity Risk Disclosure by Publicly Listed Firms: State, Drivers, and Consequences

Author: Dr Yuqian Zhang

This folder contains the datasets, methodology notes, and replication files used
to produce the figures and tables in this report. File-level descriptions are
provided inside each CSV header and in the methodology documentation included
with the report. All data are provided for academic research use; please cite
the report when reusing them.
